# Peacekeeper_3D

Developed with Unreal Engine 4.27

**Conquer the land by defeating group of enemies!**

**Controls:**
WASD — Move
Space — Jump
Left Mouse Button — Shoot

Defeat enemies to earn **XP**, level up, and unlock powerful upgrades in the **Upgrade Menu**.

Objective: **Survive and Reach end of the level**
